# ROM MOTION 웹앱 프로토타입 v0.3

## 실행 방법
1. ZIP 파일의 압축을 풉니다.
2. VS Code에서 `rom_rehab_webapp` 폴더를 엽니다.
3. 권장: VS Code 확장 프로그램 **Live Server**를 설치한 뒤 `index.html`에서 `Open with Live Server`를 선택합니다.
4. 브라우저에서 관절각 시뮬레이션과 목표각 알림음을 테스트합니다.

센서 BLE 연결은 Web Bluetooth를 지원하는 데스크톱 Chrome 또는 Edge에서 HTTPS 또는 localhost로 열어야 합니다. `file://` 직접 열기에서는 브라우저 정책에 따라 BLE가 동작하지 않을 수 있습니다.

## v0.3에 추가된 기능
- 목표 각도에 처음 도달하면 2음 신호음 재생
- 신호음 켜기/끄기 및 신호음 테스트 버튼
- 별도 센서 연결 화면
- Web Bluetooth 장치 검색, GATT 서비스 및 특성 연결
- Notify / Indicate 데이터 수신 또는 Read 특성 100ms 폴링
- 수신 패킷 수, 마지막 수신 시각, 실시간 센서 각도 표시
- BLE 연결 중에는 각도 시뮬레이터를 잠그고 실제 센서값으로 대시보드 갱신
- 연결 해제 및 연결 상태 표시

## BLE 연결 전 필요한 ESP32 펌웨어 정보
기획서에는 ESP32가 BLE로 10Hz 데이터를 전송한다는 내용은 있지만, BLE **Service UUID**와 **Angle Characteristic UUID**, 특성 데이터 인코딩은 정해져 있지 않습니다. 실제 장치 연결 전에 펌웨어에서 사용한 두 UUID를 센서 연결 화면에 입력해야 합니다.

현재 웹앱은 각도 특성에서 다음 텍스트 형식을 받도록 구현되어 있습니다.
- 숫자 텍스트: `60` 또는 `60.5`
- JSON 텍스트: `{"angle":60}`

특성은 Notify 또는 Indicate를 지원하는 것이 권장됩니다. Read만 지원하면 웹앱은 약 100ms 간격으로 읽기를 시도합니다. 센서의 BLE 데이터가 바이너리 형식이라면 `handleSensorPayload()` 파서를 펌웨어 형식에 맞게 수정해야 합니다.

## 현재 기능 및 한계
- 관절각 0~180° 시뮬레이션 및 게이지
- 목표각 설정, 영점 보정
- 목표각 도달 후 10° 이하 복귀 시 반복 카운트
- 최대 각도, 반복 목표 진행률, 이벤트 로그 및 CSV 내보내기
- BLE UI와 브라우저 연결 코드는 포함되어 있지만, 실제 ESP32 펌웨어 UUID/데이터 형식 확인 전에는 하드웨어 연결을 보장할 수 없습니다.

중요: 이 프로젝트는 제작 중인 프로토타입으로, 측정 정확도·반복 판정·알림 기능은 의료적으로 검증되지 않았습니다. 실제 치료나 재활 처방의 대체 수단으로 사용하지 마세요.
